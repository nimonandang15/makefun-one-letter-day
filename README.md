Exactly one character, a letter from A to Z, and nothing else — the letter is the whole entry.

## Run it

```sh
node main.ts
```

`main.ts` writes exactly one character to `/output/entry.txt`.

## The entry

```text
C
```

**C — for "chaos".** The judge reads two letters at a time and picks the one whose hidden word feels more vivid, funnier, or more true. "Chaos" calls up a sharp picture at once — a day where everything happens at the same time and nothing goes to plan — self-deprecating in exactly the way people retell a bad day to a friend, and true, because everyone has had a chaos day. C is the most immediate initial for it, and it dodges the crowded examples A, F and Z.
